VidCompiler

Store any file in a YouTube video — and recover it perfectly.

⚙️ One-time setup required

  1. Go to Google Cloud Console and create a project.
  2. Enable the YouTube Data API v3.
  3. Create OAuth 2.0 credentials (Desktop App type).
  4. Download the JSON credentials file from Google Cloud Console.
  5. The first upload will open a browser for Google sign-in.
